## Setting up the new machine

```bash
git clone https://github.com/masiarek/star-voting-library
cd star-voting-library && uv sync
git config core.hooksPath STARVote_LH_tabulation_engine/tools_adam/scripts/git-hooks
uv run pytest                       # 1011 tests at handoff; all green
uv run --group docs mkdocs serve    # local site preview
```

Two traps worth carrying over: install **`pref_voting`** before running the suite (without it, five `_RANGE_tabulated` mirrors get rewritten in place and look like real failures), and never raise the `mkdocs-same-dir` / `mkdocs-redirects` pins without checking — they are capped at the last releases free of the MkDocs-impersonating `properdocs` package.
